# 💤 Snoozy

[![Status](https://img.shields.io/badge/status-in%20development-yellow)](https://github.com/yourusername/sleep-cycle-calculator)
[![Kotlin](https://img.shields.io/badge/kotlin-blue.svg)](https://kotlinlang.org)
[![Compose](https://img.shields.io/badge/compose-brightgreen)](https://developer.android.com/jetpack/compose)

Приложение для расчета оптимального времени пробуждения на основе циклов сна. Помогает просыпаться бодрым и отдохнувшим, вычисляя идеальное время для будильника с учетом фаз сна.

## ✨ Особенности

- 📱 Material 3 дизайн с поддержкой темной темы
- 🧮 Расчет циклов сна (стандартный цикл 90 минут)
- ⏰ Учет времени засыпания 
- 🔄 Автоматический пересчет при изменении параметров
- 📊 Визуальное отображение циклов сна
- 💾 Сохранение пользовательских настроек
- 🎯 Простой и интуитивный интерфейс

## 🚀 Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **Архитектура:** MVVM + Clean Architecture
- **Навигация:** Jetpack Navigation Compose
- **Асинхронность:** Kotlin Coroutines + Flow
- **Хранение:** DataStore Preferences / Room
